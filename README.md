# TwitchRecommender

A learning project for channel recommendations: offline data preparation, popularity baseline, two-tower training, FAISS retrieval and a local Python API alongside a Java backend.

- [Project documentation and learning notes](docs/README.md)
- [Python setup and run instructions](recommendation/README.md)
- [Next milestone: approved Spring Boot migration design](docs/notes/Spring-Boot-Migration-Design.md)

The Python retrieval service is implemented. Spring Boot migration, Java-to-Python integration, the recommendation frontend and application event collection are upcoming work. Generated data and model artifacts stay local.
